# PROJECT CONTEXT — E-Commerce Platform

## Project Purpose

Build a React-based E-Commerce Platform for the August 31, 2026 project competition.

The goal is to demonstrate practical software development skills using React, JavaScript, React Router, Redux Toolkit, APIs, Git, and GitHub.

The project is being developed incrementally rather than copying a complete project from AI.

---

## Competition Scope

Current competition version is frontend-focused.

### Included

- React
- JavaScript
- React Router
- Redux Toolkit
- Fetch API
- Bootstrap/Tailwind when appropriate
- Git
- GitHub
- Free/public APIs where appropriate

### Not included in competition version

- Spring Boot
- Hibernate/JPA
- MySQL

Backend/database technologies may be added after the competition.
